1. PROJECT IDENTITY & TECH STACK
--------------------------------------------------------------------------------
Product    : On-prem IT Service Desk — tickets, serialized assets, consumable
             stock, service requests, KB, workflow automation, reporting.
             No cloud/S3/SMTP required for local dev (all env-swappable).
Backend    : Django 6.0 + Django REST Framework 3.16.1
             djangorestframework-simplejwt 5.5.1 (JWT, 60-min access /
             1-day refresh, blacklist on logout), django-cors-headers 4.9
             Celery 5.6.3 + redis 8.1.0, openpyxl 3.1.5, reportlab 5.1.0,
             python-docx 1.2.0  (backend/requirements.txt)
Frontend   : React 19.2.8 + Vite 8.3.0, axios 1.20, react-router-dom 7.18
             (installed but routing is hash-based in App.jsx, not react-router),
             oxlint 1.81, vitest 5.0 + jsdom + @testing-library/react.
             (frontend/package.json)  No build step beyond `vite build`.
DB         : SQLite db.sqlite3 in dev (backend/db.sqlite3, git-ignored).
             Production requires PostgreSQL (KNOWN_LIMITATIONS.md).
Auth       : Custom User model (email login), 4 roles: system_admin,
             it_manager, it_support, employee; + is_superuser check.
             EmailBackend + ModelBackend. JWT via /api/token/ + /token/refresh/.
             Tokens in localStorage; axios interceptor refreshes on 401.
API base   : http://127.0.0.1:8000/api (api.js baseURL — paths must NOT
             include the /api prefix again; that bug bit Phases 13/14).
UI base    : http://localhost:5173 (Vite dev). Hash routing: #/tickets etc.
Demo users : admin@local / manager@local / support@local / employee@local
             (passwords in accounts/management/commands/seed_defaults.py;
             seed: 7 ticket cats, 6 asset cats, 3 depts, 4 demo users).
Celery     : celery -A config.celery worker / beat (Redis localhost:6379).
             Beat schedule (settings.py CELERY_BEAT_SCHEDULE), 4 entries:
               check-sla-escalations        tickets.tasks  every 300s
               check-maintenance-reminders  assets.tasks   every 3600s
               process-inbound-emails       common.tasks   every 60s
               run-scheduled-reports        common.tasks   every 300s
Env        : Root .env (git-ignored), loaded by settings.py _load_root_env().
             .env.example at root documents every var (SECRET_KEY, DEBUG,
             ALLOWED_HOSTS, CORS, SMTP, S3, IMAP intake, Celery, attachments).
